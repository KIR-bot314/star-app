# iOS-обёртка «Звёздочки»

Приложение из одного `WKWebView`, которое открывает https://kir-bot314.github.io/star-app/.
Нужно только для того, чтобы «Звёздочки» можно было добавить в «Упрощённый доступ»
на детских iPhone: туда попадают лишь настоящие приложения, веб-приложения с экрана «Домой» не видны.
Вся логика остаётся на GitHub Pages, обновления приложения не требуют пересборки.

## Важно: TestFlight не подходит

Телефоны детей работают на детских Apple ID (Семейный доступ). В TestFlight нельзя
присоединиться к тестированию до 13 лет, а детские учётные записи Apple блокируются там
и после 13 — ограничение по типу учётной записи, отключить его нельзя.

Поэтому распространение только **Ad Hoc**: сборка подписывается под конкретные телефоны
по их идентификаторам (UDID). На телефоне не нужен ни Apple ID, ни вход куда-либо,
ни приглашение — приложение просто устанавливается.

## Сборка Ad Hoc `.ipa` (друг с платным аккаунтом разработчика)

1. developer.apple.com → Certificates, Identifiers & Profiles → **Devices** → «+» →
   добавить два UDID (пришлёт Кирилл). Это обязательно сделать **до** экспорта:
   в профиль попадают только устройства, зарегистрированные на момент подписи.
2. **Если архив уже собран** (например, для TestFlight) — пересобирать не нужно:
   Xcode → Window → Organizer → выбрать архив → **Distribute App** → **Release Testing**
   (в Xcode 14 и старше называется Ad Hoc) → Export.
3. **Если архива нет** — одна команда:

   ```bash
   git clone https://github.com/KIR-bot314/star-app.git && cd star-app/ios
   ./build.sh TEAM_ID
   ```

   `TEAM_ID` — 10 символов, developer.apple.com → Membership details.
   Требуется Xcode 15+ со входом в Apple ID команды (Xcode → Settings → Accounts).
4. Отправить Кириллу два файла: `Zvezdochki.ipa` и `manifest.plist`
   (скрипт кладёт их в `build/ipa/`, ручной экспорт — в выбранную папку).

Что делает скрипт: `xcodebuild archive` с автоматической подписью, затем `-exportArchive`
методом `release-testing`. App ID, сертификат и профиль создаются автоматически
(`-allowProvisioningUpdates`), в профиль попадают все устройства, зарегистрированные в аккаунте.
Если bundle id `com.kirillborisov.zvezdochki` окажется занят другой командой:
`./build.sh TEAM_ID com.другой.id` и сообщить Кириллу новый id.

Профиль Ad Hoc живёт год. Через год повторить экспорт, код менять не нужно.
Добавить ещё один телефон позже = зарегистрировать его UDID и экспортировать заново.

## Установка на телефоны (Кирилл)

Файлы `Zvezdochki.ipa` и `manifest.plist` кладутся в эту папку и пушатся. После этого на детском iPhone
(выйдя из Упрощённого доступа) в Safari открыть https://kir-bot314.github.io/star-app/ios/install.html
и нажать «Установить». Затем: Настройки → Универсальный доступ → Упрощённый доступ →
Управление приложениями → добавить «Звёздочки».

Если установка не начинается, проверить на детском телефоне:
Настройки → Экранное время → Контент и конфиденциальность → Покупки в iTunes Store и App Store →
**Установка приложений: Разрешить**. Детские учётные записи часто имеют это выключенным.

Запасной способ без сайта: подключить iPhone кабелем к Маку и перетащить `Zvezdochki.ipa`
на устройство в боковой панели Finder.

## Где взять UDID

Подключить iPhone кабелем к Маку → Finder → выбрать телефон в боковой панели →
под названием нажать на строку с моделью, она переключится на UDID → правый клик → Копировать.
