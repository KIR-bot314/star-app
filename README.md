# Звёздочки ⭐

Семейный трекер звёздочек для трёх iPhone: один родительский и два детских.
Веб-приложение без App Store: открывается в Safari и добавляется на экран «Домой».

Адрес: **https://kir-bot314.github.io/star-app/**

## Как устроено

- `index.html` — всё приложение (интерфейс, анимации, синхронизация).
- `config.js` — единственный файл с настройками: конфиг Firebase и имя «комнаты» в базе.
- `manifest.webmanifest`, `icon-180.png`, `icon-512.png` — имя и иконка для экрана «Домой».

Общие данные (дети, награды, журнал звёзд, заявки, PIN) лежат в Firebase Realtime Database
под `rooms/<room>` и приходят на все телефоны живой подпиской. Каждое действие пишет только
свой кусочек (звезда — отдельной записью журнала, заявка — по ключу ребёнка), поэтому телефоны
не затирают друг друга. На самом телефоне хранится только его режим (чей это телефон) и кэш
последнего состояния, чтобы открываться без сети.

Пока в `config.js` стоит `firebase: null`, приложение работает локально, без синхронизации.

## Настройка Firebase (один раз)

1. Открыть https://console.firebase.google.com → **Add project** → любое имя (например `star-app`) →
   Google Analytics можно выключить → **Create project**.
2. В меню слева **Build → Realtime Database → Create database** → регион `europe-west1 (Belgium)` →
   **Start in locked mode** → Enable.
3. Вкладка **Rules** → заменить всё на текст ниже (имя комнаты должно совпадать с `room` в `config.js`) → **Publish**:

   ```json
   {
     "rules": {
       "rooms": {
         "hXZzRoFouLMW0HimIPyZIEypOSOz": {
           ".read": true,
           ".write": true
         }
       }
     }
   }
   ```

4. Шестерёнка → **Project settings** → внизу **Your apps** → значок `</>` (Web) → имя `star-app`,
   Firebase Hosting не нужен → **Register app** → скопировать объект `firebaseConfig`.
   В нём должно быть поле `databaseURL` (адрес вида `https://…-default-rtdb.europe-west1.firebasedatabase.app`).
   Если поля нет — адрес виден вверху вкладки **Data** в Realtime Database.
5. Вставить объект в `config.js` вместо `null` и закоммитить. GitHub Pages обновится примерно за минуту.

Бесплатного тарифа Spark (1 ГБ данных, 10 ГБ трафика в месяц, 100 одновременных подключений)
семье хватит с большим запасом.

Данные некритичные, поэтому защита — только несловарное имя комнаты: без него в базу не попасть,
но тот, кто знает адрес сайта, может открыть приложение (в нём есть PIN на родительский режим).

## Установка на iPhone

1. Открыть в Safari адрес https://kir-bot314.github.io/star-app/
2. Нажать кнопку «Поделиться» (квадрат со стрелкой) → **На экран «Домой»** → **Добавить**.
3. Дальше открывать только с иконки: у приложения с экрана «Домой» своя память,
   поэтому режим телефона запоминается именно там.
4. На детском телефоне при первом открытии тапнуть карточку ребёнка — телефон закрепится за ним.
   На родительском оставить как есть и заходить через **🔒 Родителям** (код по умолчанию 1234,
   поменять в родительском режиме).
5. Если детский телефон нужно перевести обратно: подержать аватар ребёнка 1,5 секунды →
   ввести PIN → раздел **Этот телефон** → **Спросить**.
